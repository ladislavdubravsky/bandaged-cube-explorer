## Destination and scope

A user supplies a reference bandage shape, without a colored scramble or shape
scramble. The output is a reusable stage plan with witnessed algorithms,
recognition rules and application instructions for every reachable colored
state whose bandage shape has already been restored to that reference.

Human shape restoration is explicitly deferred. Loops may leave the reference
shape internally, returning to it at whole-algorithm boundaries. Optional colored
examples and application helpers consume the generated method; generation does
not depend on them.

The guide should explain what to solve, how to recognize each case, what prior
features are restored, which unsolved blocks may change, which definitions must
be remembered, and why the complete policy terminates. Computational completeness
and human usability are separate. A valid large table is not automatically a
pleasant human method, and not every bandaging necessarily admits a small one.

## Reuse and mathematical contracts

Keep implementation in v2 and preserve existing mechanics and legacy behavior.
Reuse Rust shape exploration and move replay, Python isotropy and block actions,
GAP exact group facts, kernel analysis, LoopExpression witnesses and existing
graphics. The fixed frame, six outer faces, actual inventory and observable
48-sticker coloring are authoritative. Do not silently merge bonds, complete
hulls, reflect algorithms, or change reference roots.

Let H be the faithful colored group generated by all legal loops at the reference
shape. A reduced generating set needs complete-loop coverage evidence. Select
H = H0 >= H1 >= ... >= Hm = {identity}. Initially use recognizable features:
place a specified physical block at its home footprint, or fully solve that block
including observable orientation. Arbitrary Boolean predicates need not define
subgroups. Orientation with position forgotten is not automatically a feature
action. Standard stabilizers, actions and cosets supply the algebra.

With right actions in execution order, a stage case is the right coset
H(i+1) g. A representative t gives correction t^-1, since g t^-1 lies in H(i+1).
Every correction is a legal reference loop belonging to Hi and restores earlier
features at its endpoint. Its factors can disturb those features internally.
Later blocks remain unconstrained. Observation fibers must be exact cosets,
with representative-independent case behavior.

There are [Hi:H(i+1)] cases including the already-correct case. Every case needs
a correction or a verified terminating rule. Terminal triviality includes
observable twists, flips and symmetric-block rotations, not just footprints.
The product of stage indices is fixed at |H| and cannot score chain quality.

Coverage and quality have separate statuses. Bounded quality search retains a
complete baseline; stopping exact preparation reports unmet obligations and
never means unreachability. Exact enumeration has opt-in caps, without a new
default resource limit. Later symbolic coverage can use exact group/intersection
orders; sampling supplements proofs and does not replace them.

## Public artifacts and architecture

Implemented modules:

| Module | Responsibility |
| --- | --- |
| human_chains.py | Semantic block features, exact subgroups/cases, witnessed group |
| human_methods.py | Complete policies, recognition, application and verification |
| human_method_io.py | Versioned portable JSON, fingerprints and independent loading |
| human_witnesses.py | Immutable portable original-loop witness owners |
| human_algorithms.py | Bounded fixed-chain discovery, alternatives and quality metrics |
| human_chain_search.py | Shared-pool greedy/beam chain comparison and complete Pareto policies |
| human_render.py | Initial readable case-table Markdown guide |
| human_repertoire.py | Shared masters, bounded deletion, verified instruction transitions and ranks |
| human_repertoire_io.py | Portable repertoire wrappers and independent rule/cost validation |
| human_repertoire_render.py | Concrete cue lookup and compressed instruction-family guides |

Add symbolic backends when their responsibilities warrant separate modules.
Extract shared internals rather than duplicate algebra or
silently invoke the exact-scramble solver.

Existing workflow:

```python
plan = c.plan_human_stages(shape, strategy="placement_then_orientation", ...)
method = c.synthesize_human_method(shape, ...)
search = c.improve_human_method(method, mode="structured", ...)
search.method.save("method.json")
search.method.write_guide("method.md")
search.save("algorithm-search.json")
selection = c.select_human_chain(shape, preference="recognition", ...)
selection.method.save("selected-method.json")
selection.save("chain-search.json")
restored = c.load_human_method("method.json")
result = restored.apply(state)  # optional consumer; no GAP or new factorization
repertoire = c.generator_human_repertoire(selection.method)
repertoire.write_guide("generator-method.md")
repertoire.save("generator-repertoire.json")
```

Artifacts retain reference specification/inventory/frame, exact group facts,
original physical witnesses, ordered features and cases, shared expression
definitions, move words and costs, coverage evidence and explicit quality scope.
Loading independently replays/rechecks the claims. Inspection reports retain
settings and tradeoffs separately from the executable method format.

## Deliveries

### Delivery 0 — Capture the baseline and freeze the contract (complete)

Promoted the chain experiment and froze shape-only, endpoint-preservation and
coverage semantics. Exact H/P/K and both automatic chains are reproduced for
Alcatraz, Bicube Fuse, Shark Fin Soup and Most Signatures Cube. The largest
validated explicit group has 10,368 elements; this is measured scope, not a
universal performance threshold. Deterministic results and machine diagnostics
are separate. See [research results](../v2/research-results/README.md).

### Delivery 1 — Exact recognizable stage plans (complete)

Added immutable block-feature/stage/group records, both automatic strategies,
manual chains, redundant-feature skipping, implied features and terminal checks.
Every group element retains an original-loop BFS-tree witness. Full native-loop
coverage, faithful actions, equivariance, exact cosets and independent kernel
basis are verified. Caps stop before enumeration. All four fixtures reproduce
the baseline; 16 dedicated tests and the then-current 210-test suite passed.

This is chain structure only; it does not by itself claim a usable method.

### Delivery 2 — Complete correction policies (complete)

Compiled inverse BFS coset representatives into complete policies with shared
definitions, example states, recognition, next_step and application traces.
Wrong references, unrestored shapes, outside-H residuals and incomplete methods
are distinct. Version-one JSON loading proves coverage without GAP and preserves
saved local witness IDs. Shape-only CLI accepts fixtures, inline labels, label
files or puzzle reference specifications, and writes JSON plus Markdown.

All 420 imported root states from the three small fixtures solve with compiled
and reloaded methods (840 applications). Dedicated method, CLI and stage
regressions passed. Quality remains computational_baseline.

### Delivery 3 — Stage-aware discovery of nicer algorithms (complete)

Added bounded original-loop, shallow-word and structured searches. Candidates
include inverses, powers, commutators, conjugates, same-protected-coset quotients
and witnessed Schreier constructions. Search targets feature cases rather than
an exact residual permutation, and searches directly within stage stabilizers.
Several short/simple alternatives are retained; complete baseline corrections
remain available under every quality cutoff.

Shared immutable witness owners merge saved/native leaves without changing old
IDs or actions. Final selected policies are verified. Exact full-method mean and
worst HTM guard against local improvements making later stages or boundary
cancellations worse. QTM and definition/reuse costs are also reported, without
global QTM, shared-memory or shortest-word guarantees.

Default quality budgets: 3,000 proposed expressions, 2,000 settled macro states,
32 native seeds, depth three, one round, 24 stage edges, three alternatives,
120 candidate HTM and 480 expansion moves. Duplicate, identity and pruned
proposals count. Reference preparation, final proof and full-group metrics are
outside these budgets. No wall-clock quality cutoff is implemented. CLI exposes
opt-in improvement, budgets and a separate search report; invalid budgets and
file aliases are rejected before preparation/writing.

[Equal-budget comparisons](../v2/research-results/human-algorithms.md) reproduce
byte for byte. Mean/worst HTM: Alcatraz 54.86/94 → 50.40/86, Bicube 29/57 →
26.70/49, Shark 50.28/89 → 22.67/35. Shark's late 48/50-turn corrections become
19 each. Short native loops provide most gains; shallow search improves Bicube
further; structured search adds no execution saving on these fixed chains at
this budget. Used original definitions increase on Bicube and Shark. The local
GAP installation lacks orb; no new dependency was added and bounded Schreier
discovery does not claim to compute a complete SGS.

Validation: 13 discovery, 15 method-CLI, 12 method and 11 existing CLI tests pass
(51 total), including 840 improved/reloaded applications, full alternative
fiber checks, legal replay, bounds, duplicate accounting, nonzero roots,
determinism, repeated search and full-method fallback.

### Delivery 4 — Select chains using available algorithms (complete)

- Compare placement-first, fully-solve-one-block, supplied manual and ordinary
  faithful-point-chain baselines. Keep point chains research-only if their
  recognition does not fit the current block guide format.
- Start with greedy selection and add bounded beam/lookahead over recognizable
  placement/full-block features. Allow interleaving and implicit adjacent-stage
  merging through full-block features.
- Score actual available correction words with unsolved blocks free. Include
  future stages and remaining workspace; a cheap first stage can leave a costly
  final stabilizer. Partial branches are not complete-method evidence.
- Reuse the enumerated reference group, action summaries, subgroup/feature
  calculations and a fixed witnessed word pool across chains. Preserve multiple
  prefixes for equal subgroups when recognition, prior vocabulary or physical
  cancellations differ. Disclose the pool's discovery-chain origin and budget.
- Retain a small Pareto set using complete-method mean/worst execution,
  recognition cases, number of stages and original/shared definition costs.
  Select a documented preference rather than hide an opaque weighted score.
- Keep complete baselines despite chain-search limits. Independently verify
  every exported complete policy and report heuristic limits honestly.

Acceptance: compare complete methods on the same fixtures and recorded budgets.
Reproduce Alcatraz's six-stage 2/3-case versus five-stage 9-case tradeoff.
Demonstrate the effect of algorithm-aware choice, or retain the simpler baseline
with an evidence-based explanation. No global optimality or human-review claim.

### Delivery 5 — Shared repertoire and compressed recognition

Select a common algorithm vocabulary across stages, including inverse/power and
setup/undo rules, and verify complete stage reachability after changes. Begin
with greedy removal of redundant definitions; use expensive joint optimization
only if measurements justify it. Compress case tables into verified inverse
pairs, repeated rules with progress ranks, setups and actual proper symmetries.
Every compressed rule must expand to exhaustive valid cases; fallbacks stay
explicit. Never assume an abelian kernel is central or reorder corrections
across placement actions without proof. Record execution versus memory tradeoffs.

### Delivery 6 — Usability and thorough human review

Review entry point: [BandagedPocketCube.ipynb](../v2/examples/BandagedPocketCube.ipynb)
now generates all recognition cases as cube diagrams. Select transparent 3D or
opposite-corner views through `DiagramMode` and face colors before evaluation.
Opposite-corner views mark solved blocks with light tints, the current target
with the selected face colors, and all other blocks white. Transparent views use
the UFR diagonal projection and color only face centers and current targets.
Placement cases include every attainable target orientation.
Algorithms appear in a table before stages, with turn sequences, block actions, and exact structured
physical notation (`S^A` for conjugation) beside expanded words and without move
counts or witness provenance. Every instruction repeats its identifier and
complete turns; rotated instructions use diagrams in the required starting grip.
The guide omits preparation, color legends, and repeated stage footprint instructions.
Exact white face colors get ten thin diagonal stripes spanning each colored sticker;
plain white hidden stickers remain unmarked.
The review cell refreshes Python presentation modules on each evaluation,
preventing an open kernel from regenerating obsolete guides from cached imports.
The supplied shape has 580 shapes and 432 reference states. The original
optimized example taught six shared masters over five stages.

**Initial human review and resulting direction.** The user accepted the
presentation, but found the generated algorithms too random and complicated to
remember. For this puzzle the three reduced isotropy generators were easier to
use with powers and cube rotations. Preserve the algorithm-optimization work,
but shelve further improvements for now. The notebook now uses
`generator_human_repertoire(selection.method)` to retain the selected five-stage
chain (orders 432 → 72 → 18 → 6 → 3 → 1), while expressing every correction using
only those three original masters in analysis order. No additional learned
definitions are introduced. Complete corrections restore earlier features;
their constituent generator applications may temporarily disturb them.

The constructor also accepts a reference shape, block analysis or prepared
stage plan. Direct shape input skips word discovery and chain-quality search
and uses the requested strategy or explicit features with reduced-generator
group witnesses. It retains exact finite-group preparation and an optional
element cap. Existing guide, diagrams, recognition, application and portable
save/load APIs remain available; loaded artifacts apply without GAP. This
option provides a fixed vocabulary, without a shorter-word or human-quality
claim. Shape restoration and symbolic scaling remain deferred.

### Delivery 7 — Symbolic scaling

Use core GAP stabilizers, prescribed bases, tracked strong generators,
coset/orbit actions and transversals without listing H. Preserve physical word
witnesses through every operation. Exact group/intersection certificates can
prove vocabulary coverage but do not themselves provide human recognition.
Cross-check against explicit small groups; add packages such as genss/orb only
after measured benefit. Profile before moving Python hotspots to Rust. This
delivery may move earlier if explicit computation becomes the bottleneck.

Acceptance: handle a case beyond practical explicit-H scope with certified
coverage and legal words, reporting any unmet human-quality or generation goal.

### Delivery 8 — General-input completion and integration

Exercise strongly bandaged, noncuboid, core-bonded and symmetric inventories.
Use Most Signatures Cube as the first larger regression and the unbandaged cube
to ensure symbolic scaling does not depend on colored-state enumeration; a
competitive ordinary-cube human method is not required. Sample diverse atlas
representatives by geometry/action structure. Finalize API/CLI, error semantics,
schema migration, guides, optional dependencies and documentation. Atlas-wide
synthesis remains a separate optional project. Human shape restoration remains
outside this plan.

## Verification and resource behavior

Verify algebraic containment, exact action/coset behavior, index product and full
terminal identity. Legally replay all exported words and prove endpoint promises
on whole stage fibers. Exhaustively apply complete methods to every H element
on small fixtures, independently import colors, round-trip artifacts and reject
corrupted semantic claims. Test trivial H, fixed footprints with nontrivial
orientations including order four, coupled constraints, nonzero roots, outside-H
residuals, unrestored shapes, explicit resource stops and actual symmetry rules.

Run relevant regressions; Rust checks are needed when Rust changes. Avoid tests
that merely freeze arbitrary heuristic rankings. Exact backend limits remain
opt-in. Quality budgets and used counts are recorded. No timeout proves
unreachability or the absence of a pleasant method. Cache keys include exact
reference/inventory/frame, features, witnesses and backend versions, not just
abstract group order or signature.

Keep deterministic mathematical/physical records separate from machine timing
and memory diagnostics. Retain experiments that explain later design decisions.
Human memory/recognition proxies are measurements of the generated artifact,
not validated psychological difficulty scores.

## Research directions and sources

Standard group actions and stabilizer chains are sufficient for the initial
feature family; short witnessed words and human recognition need additional
engineering. Revisit symbolic packages, kernel-coordinate recognition, deeper
macro search or pattern databases when a concrete difficult stage warrants it.

- [GAP actions](https://gap-system.github.io/gap/doc/ref/chap41_mj.html) and
  [stabilizer chains](https://gap-system.github.io/gap/doc/ref/chap43_mj.html).
- [Egner and Püschel's puzzle work](https://people.inf.ethz.ch/markusp/examples/puzzles/puzzles.html):
  localized words and algorithm-informed bases; consult the authors' erratum
  before relying on the original word-chain lemma.
- [Minkwitz](https://www.sciencedirect.com/science/article/pii/S0747717198902024):
  short generator words are a separate problem from an ordinary SGS.
- [orb short subgroup generators](https://gap-packages.github.io/orb/doc/chap7.html)
  and [genss](https://gap-packages.github.io/genss/doc/chap3_mj.html).
- [Korf's reusable macros](https://cdn.aaai.org/AAAI/1982/AAAI82-039.pdf) and
  [Hernádvölgyi's stage macro search](https://cdn.aaai.org/AAAI/2000/AAAI00-158.pdf).

After each delivery update shipped behavior, validation, observed quality,
bottlenecks and the next question, preserving shape-only input, physical
witnesses, full modeled orientation and honest coverage reporting.
